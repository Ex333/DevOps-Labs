# Docker Notes - Day 2

## Commands

- `docker build` - build my own image.
- `docker images` - show all images.
- `docker run` - create and start container.
- `docker logs` - check what is happening inside container.

## Dockerfile

- `FROM` - choose base image.
- `COPY` - copy my files into image.

## What I learned

- Dockerfile is a file where I write instructions to build image.
- Image is used to create container.
- I can copy my own HTML page into nginx image.
- `-p 8080:80` means port 8080 on my computer and port 80 inside container.
- I can build my own image and run container from it.
